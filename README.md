# manual_AI
Manual AI is an offline, AI-powered assistant designed to help users understand technical manuals and troubleshoot complex issues more efficiently. It allows users to upload PDF manuals, ask questions in natural language, and receive answers based on relevant information extracted from the documents.

Built using Python, Streamlit, and Ollama, the project uses locally running AI models to understand questions, search relevant sections of technical documentation, and generate context-aware responses. It retrieves useful text passages from the uploaded manual and presents the corresponding source pages, helping users verify answers against the original documentation.

The application is designed with privacy and offline accessibility in mind. After the required software libraries and AI models have been downloaded, document processing and question answering can run locally on the user's computer without relying on cloud-based AI services. This makes it particularly useful for technical environments where internet access is limited or documentation must remain private.

Manual AI aims to simplify the process of navigating lengthy technical documents, reducing the time spent searching through hundreds or thousands of pages to find specific procedures, explanations, or troubleshooting instructions.

The initial version supports text-based PDF manuals and provides a foundation for building a more comprehensive technical troubleshooting assistant. Future enhancements may include OCR for scanned documents, circuit-diagram analysis, improved retrieval across large document collections, persistent document indexing, and support for complex, step-by-step troubleshooting workflows.

The long-term goal is to create a lightweight, private, and practical AI assistant that helps engineers and technical users find relevant information quickly, understand documented procedures, and solve problems more effectively using their existing technical documentation.
